# SPADAku

**Kuliah jadi lebih santai.** Aplikasi Android untuk mengakses **SPADA Universitas Muhammadiyah Metro** langsung dari HP.

### 📥 [Unduh SPADAku.apk (versi terbaru)](https://github.com/Biyu21/SPADAku-Release/releases/latest/download/SPADAku.apk)

Android 7.0 ke atas · ±98 MB · masuk dengan akun SPADA-mu sendiri

---

## Fitur

| | |
| **Beranda** | Kuliah berikutnya, persentase kehadiran, dan tugas paling mendesak dalam sekali lihat |
| **Notifikasi** | Dikabari saat absen dibuka, ada tugas baru, atau deadline makin dekat |
| **Absen dari HP** | Termasuk absen yang memakai password dosen. Kehadiran langsung tercatat di SPADA |
| **Scan & kirim tugas** | Foto kertas jawaban, terpotong rapi jadi PDF, lalu kirim ke dosen dari HP |
| **Pengingat deadline** | Atur sendiri, dari H-7 sampai 1 jam sebelum, plus jam tenang di malam hari |
| **Jadwal & agenda** | Jadwal kuliah mingguan bersama agenda pribadi dan pengingatnya |
| **Mata kuliah** | Pertemuan, materi yang bisa dibaca offline, tugas, dan riwayat absen |
| **Kunci sidik jari** | Lindungi akunmu di HP |
| **Mode gelap** | Nyaman untuk belajar malam |

## Cara pasang

1. Ketuk link **Unduh SPADAku.apk** di atas, lalu tunggu sampai selesai terunduh.
2. Jika Chrome bertanya *"File ini mungkin berbahaya"*, pilih **Tetap download**.
   Peringatan ini muncul untuk semua aplikasi yang tidak dipasang dari Play Store.
3. Buka file `SPADAku.apk`. Jika diminta, izinkan **Instal aplikasi tidak dikenal** untuk Chrome/File Manager.
4. Ketuk **Instal**, lalu masuk dengan **NPM & password SPADA**.

**Update:** cukup unduh lagi dari link yang sama, lalu pasang. Aplikasi akan diperbarui tanpa menghapus data.

## Tentang

SPADAku adalah **alternatif akses** SPADA melalui Android dan terhubung ke **layanan resmi Moodle** di server SPADA (`spada.ummetro.ac.id`).
SPADAku **bukan** sistem akademik baru dan **tidak menggantikan** website resmi SPADA. Datanya sama persis dengan yang ada di website.

- Login langsung ke server SPADA. Password tidak dikirim ke pihak lain.
- "Ingat saya" disimpan terenkripsi, hanya di HP-mu.
